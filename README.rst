Installation
============


1. from binaries
~~~~~~~~~~~~~~~~

.. code-block::

    pip install skepsi

2. from source
~~~~~~~~~~~~~~

**Step 1.** Get the latest source by cloning this repo::

    git clone https://gitlab.com/grg_edge/skepsi.git

**Step 2.** Install requirements::

    pip install -r requirements/default.txt

**Step 3.** Install skepsi via::

    pip install .

or::

    pip install -e .

**Step 4:** Enjoy!
