# Citing Thetan

If Thetan helps your research, please cite the paper:

> Eleftherios Garyfallidis, Serge Koudoro, Jong Sung Park, Sai Prajwal Reddy.
> *Thetan Berserker Clustering.* IEEE Transactions on Pattern Analysis and
> Machine Intelligence, 2025.

```bibtex
@article{garyfallidis2025thetan,
  title   = {Thetan Berserker Clustering},
  author  = {Garyfallidis, Eleftherios and Koudoro, Serge
             and Park, Jong Sung and Reddy, Sai Prajwal},
  journal = {IEEE Transactions on Pattern Analysis
             and Machine Intelligence},
  year    = {2025}
}
```

Thetan is developed at Indiana University Bloomington and the University
of Michigan, and released under the BSD license.
